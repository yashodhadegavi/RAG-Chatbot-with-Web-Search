# RAG-Chatbot-with-Web-Search
AI chatbot combining RAG with web search. Upload a PDF and ask questions in natural language; if the answer isn't in the document, it searches the web automatically. Every answer shows its source. Includes chat memory and a model selector. Built with Python, Streamlit, LangChain, Groq API, FAISS and DuckDuckGo. Live on Streamlit Cloud.
